BO7 Ranked SR Tracker– Community Edition

A clean, animated ranked overlay for Black Ops 7 Ranked Play built for OBS streamers.

Designed to stay minimal on stream while allowing quick in-OBS stat updates.

✨ Features

Animated rank progression (Bronze → Iridescent) and TOP 250!

Dynamic SR progress bar

Rank icon auto update

Win / Loss session tracker

3 / 5 / 10 win streak glow effects

SR gain/loss floating animations

Click-to-edit popup inside OBS

Minimal, compact layout (perfect above or below webcam)

🎮 How It Works

The overlay runs as a Browser Source inside OBS.

To update stats:

Click the Browser Source in OBS and Interact.

A small popup panel appears.

Enter:

SR changes

Win

Loss

Reset (This will reset your daily session stats)

The popup automatically fades away after a few seconds.

This keeps your stream clean — viewers only see:

Rank

SR

Progress bar

Session record

No buttons or controls remain visible.
